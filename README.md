# LiGem - Leben in Gemeinschaft

Free, gemeinwohlorientierte platform bringing together housing communities
(Wohngemeinschaften), people looking for one, and organizations working on
communal-living topics — informieren, vernetzen, veranstalten.

- Developer/architecture docs: [CLAUDE.md](CLAUDE.md)
- Server installation: [DEPLOYMENT.md](DEPLOYMENT.md)

## Quick start (local development)

```bash
docker compose up
```

The app runs at http://localhost:3000. See [CLAUDE.md](CLAUDE.md) for
common commands (migrations, seeding, linting, etc.).
